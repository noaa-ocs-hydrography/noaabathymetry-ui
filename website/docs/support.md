# Support

## FAQ

Having trouble? Check the [Troubleshooting](/docs/troubleshooting) page for common issues and solutions.

## Report a bug

Found something that isn't working correctly? Open an issue on [GitHub Issues](https://github.com/noaa-ocs-hydrography/noaabathymetry-ui/issues).

## Request a feature

Have an idea for a new feature or improvement? Open an issue on [GitHub Issues](https://github.com/noaa-ocs-hydrography/noaabathymetry-ui/issues).

## Report a security vulnerability

For security concerns, please follow the instructions in the [Security Policy](https://github.com/noaa-ocs-hydrography/noaabathymetry-ui/blob/main/SECURITY.md). Do not report security vulnerabilities through public issues.
